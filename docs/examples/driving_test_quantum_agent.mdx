## 📚 Documentación Técnica

### Clases Principales

1. **QuantumVectorEngine**: Motor de vectorización semántica
2. **NeuralQuestionDatabase**: Base de datos con índices avanzados
3. **QuantumProcessor**: Procesamiento y validación inteligente
4. **QuantumDrivingAIAgent**: Orquestador principal del sistema

### APIs Públicas

```python
# Agente
agent.scrape_and_process(urls: list[str]) -> dict
agent.semantic_search(query: str, limit: int) -> list[dict]
agent.export_quantum(format: str, path: str) -> str

# Base de Datos
db.add_question(...) -> tuple[str, bool]
db.semantic_search(query, limit, category) -> list[dict]
db.get_recommendations(question_id, limit) -> list[dict]
db.get_statistics() -> dict
db.save_database() -> None
db.export_advanced(format, path, metadata) -> str

# Procesador
processor.clean_text(text: str) -> str
processor.extract_category(text: str, url: str) -> str
processor.validate_question(...) -> tuple[bool, str, float]
```
