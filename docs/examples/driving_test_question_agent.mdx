Este ejemplo demuestra cómo crear un agente que extrae preguntas de pruebas de conducir desde sitios web. Esto es útil para construir materiales de estudio, pruebas de práctica o aplicaciones educativas.

## Agente que responde preguntas de prueba de conducir

El ejemplo muestra cómo:

1. **Extraer preguntas de prueba de conducir** desde sitios web educativos
2. **Extraer datos estructurados** incluyendo preguntas, opciones y respuestas correctas
3. **Almacenar los datos** para referencia futura o procesamiento
4. **Navegar** a través de múltiples páginas de preguntas

## Usando BeautifulSoupCrawler

Usar <ApiLink to="class/BeautifulSoupCrawler">`BeautifulSoupCrawler`</ApiLink> cuando el sitio web de prueba de conducir sirve contenido HTML estático. Este enfoque es más rápido y eficiente para sitios web simples.

<CodeBlock className="language-python">

El crawler extrae:
- **Texto de la pregunta**: La pregunta real de la prueba de conducir
- **Opciones de respuesta**: Opciones de opción múltiple (A, B, C, D)
- **Respuesta correcta**: La respuesta correcta a la pregunta
- **Explicación**: Explicación adicional si está disponible

Los datos se almacenan en el dataset predeterminado en el directorio `./storage/datasets/default/`.

## Casos de uso

Este tipo de agente es útil para:

- **Crear materiales de estudio**: Recopilar preguntas para preparación de exámenes
- **Construir pruebas de práctica**: Agregar preguntas de múltiples fuentes
- **Plataformas educativas**: Extraer contenido para aplicaciones de aprendizaje
- **Análisis de datos**: Analizar patrones de preguntas y niveles de dificultad

## Personalización

Para adaptar estos ejemplos a sitios web específicos:

1. **Actualizar los selectores**: Inspeccionar el sitio web objetivo y modificar los selectores CSS para que coincidan con la estructura HTML
2. **Ajustar las URLs iniciales**: Reemplazar las URLs de ejemplo con sitios web reales de prueba de conducir
3. **Agregar más campos de datos**: Extraer información adicional como nivel de dificultad, imágenes o categorías
4. **Implementar validación de respuestas**: Agregar lógica para verificar respuestas si el sitio web proporciona retroalimentación

## Consideraciones éticas

Al extraer preguntas de prueba de conducir:

- **Respetar robots.txt**: Siempre verificar y respetar el archivo robots.txt del sitio web
- **Verificar términos de servicio**: Asegurar que el scraping esté permitido por el sitio web
- **Limitación de tasa**: Usar retrasos apropiados para evitar sobrecargar los servidores
- **Atribución**: Dar crédito a la fuente al usar contenido extraído
